# Dragon Taekwondo Sports Academy Website

A responsive static website built with HTML, CSS and JavaScript. It is designed for GitHub Pages hosting.

## Project files
- `index.html` – page structure and content
- `css/style.css` – layout, colours and responsive design
- `js/script.js` – mobile navigation, current year and back-to-top button
- `images/` – academy poster and photos supplied for this project

## Run locally
Open `index.html` in a web browser. For a local development server, use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new public repository named `dragon-taekwondo-academy`.
2. Upload all files and folders from this project (not just the ZIP).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then Save.
6. Wait for the published URL shown in the Pages section.

## Before publishing
- Confirm the public contact number and WhatsApp enquiry link.
- Confirm branch addresses and class timings.
- Obtain parent/guardian permission before publishing identifiable photos of children.
- Confirm the exact names and dates of tournaments and awards.
- Add names and credentials for the other two masters if you want full instructor profiles.
- Add the academy's official social media links and map links.

## Notes
This is a static website. The WhatsApp button opens a pre-filled enquiry message; it does not store form submissions in a database.
